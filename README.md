# Nur

Мобильное приложение для Service Desk CRM. Внутри — тот же интерфейс, что и в веб-версии CRM: заявки, клиенты, база знаний, администрирование (по правам пользователя). Всё, что меняется на сервере CRM, сразу доступно в приложении.

Возможности приложения сверх браузера:
- push-уведомления: новая заявка, вас назначили, новое сообщение, смена статуса — нажатие открывает заявку;
- фото с камеры и файлы с телефона во вложения;
- скачивание вложений в «Загрузки»;
- запоминает сервер и вход, обновление жестом «потянуть вниз».

## Установка (Android 8.0 и новее)

1. Откройте на телефоне страницу [Releases](../../releases/latest) и скачайте `Nur-x.y.z.apk`.
2. Откройте файл. Если Android спросит — разрешите установку из этого источника (браузера или «Файлов»).
3. Запустите Nur, проверьте адрес сервера (по умолчанию `https://crm.s-dsk.ru`) и нажмите «Подключиться».
4. Войдите своей учётной записью CRM. Разрешите уведомления, когда приложение спросит.

Обновления: начиная с 1.1.0 Nur сам проверяет новые версии и предлагает «Обновить» (долгое нажатие на значок → «Проверить обновления»). Интерфейс CRM обновляется на сервере и приходит в приложение без нового APK.
Сменить сервер: долгое нажатие на значок Nur → «Сменить сервер».

## Требования к серверу CRM

- доступ по https с доверенным сертификатом (Let's Encrypt: `sudo ./crm.sh letsencrypt почта`);
- для уведомлений — файлы Firebase на сервере (`sudo ./crm.sh push ключ.json google-services.json`); приложение берёт настройки push с сервера, пересобирать APK не нужно;
- версия CRM с поддержкой мобильного приложения (миграция `0054_push_devices`).

## Сборка

Нужны JDK 21 и Android SDK (platform 36).

```bash
cd android
./gradlew assembleDebug        # отладочная сборка: app/build/outputs/apk/debug/
```

Релиз собирает GitHub Actions при публикации тега `vX.Y.Z`:

```bash
git tag v1.0.0 && git push origin v1.0.0
```

Настройки репозитория (Settings → Secrets and variables → Actions):

| Тип | Имя | Значение |
|---|---|---|
| Secret | `NUR_KEYSTORE_BASE64` | ключ подписи: `base64 -w0 nur-release.jks` |
| Secret | `NUR_KEYSTORE_PASSWORD` | пароль ключа |
| Variable | `NUR_DEFAULT_SERVER` | адрес CRM по умолчанию, например `https://crm.s-dsk.ru` |
| Variable | `NUR_FCM_APP_ID` | Firebase → Android-приложение `ru.sdsk.nur` → App ID (`1:…:android:…`) |
| Variable | `NUR_FCM_API_KEY` | Web API Key проекта Firebase |
| Variable | `NUR_FCM_PROJECT_ID` | ID проекта Firebase |
| Variable | `NUR_FCM_SENDER_ID` | Project number (Sender ID) |

Значения `NUR_FCM_*` не секретны (они всё равно видны внутри APK), но ключ подписи и ключ сервисного аккаунта Firebase — секреты: в репозиторий их не кладите. **Ключ подписи храните в надёжном месте**: без него нельзя выпустить обновление, которое встанет поверх уже установленного приложения.
